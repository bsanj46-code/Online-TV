# Онлайн ТВ

Окремий веб- та Android-плеєр власника «Моє місто».

- 48 каналів у списку, пошук, обране, повний екран.
- 34 основні канали використовують ті самі джерела, що «Моє місто»; HTTP-джерела проходять через його обмежений HTTPS-транспорт. Для GitHub Pages дозволено лише origin `https://bsanj46-code.github.io`.
- Резервний каталог: IPTV-org, iptv.org.ua, Free-TV/IPTV. Оновлення під час щоденної публікації та завантаження каталогу при відкритті застосунку.
- Канали з тимчасовими помилками залишаються у списку для повторного запуску. Старий потік та його обробники ізолюються під час перемикання.

## Перевірка 4 листопада 2026

Для всіх 34 основних каналів отримані медіасегменти, ffprobe розпізнав H.264 та AAC. Це серверна перевірка, а не гарантія постійної доступності або перевірка фізичного Android-пристрою. Із решти 14 каналів для «ГІТ» та «Тернопіль 1» джерела повернули HTTP 503; вони доступні для повторної спроби. Для «Суспільне Київ» та «Суспільне Культура» знайдено чинні резервні джерела iptv.org.ua.

`npm test` — перемикання, пізні помилки старого потоку, повторна спроба, повний каталог і пошук. `npm run build` — збірка www.
